# M1.2.1 — Database Foundation

## Objective
Establish a production-ready database foundation for the API without resetting existing environments.

## Delivered
- SQLAlchemy engine and session lifecycle
  - `app/db/base.py`
  - `app/db/session.py`
  - `app/core/dependencies.py` (`get_db_session`)
- URL parsing and config validation for MySQL/Redis connection strings
  - `app/core/url_parsers.py`
  - `app/core/config.py`
- Initial model and migration baseline
  - `app/models/system_setting.py`
  - `alembic/versions/20261112_0001_create_system_settings.py`

## Migration policy
- Forward-only Alembic migration chain.
- No destructive reset (`down -v`) required.
- Existing data/volumes are preserved.

## Validation
- `docker compose exec -T api alembic upgrade head`
- `docker compose exec -T api python -m pytest -q tests`
- `.\scripts\verify.ps1`
