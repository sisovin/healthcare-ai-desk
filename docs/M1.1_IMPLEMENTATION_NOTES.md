# M1.1 Implementation Notes

- Modular monolith for the first release.
- Docker Compose for local Windows development.
- FastAPI is the API boundary.
- React/Vite is served by the Vite development server.
- Browser API requests use `/api` and Vite proxies to `api:8000`.
- MySQL and Redis are local service dependencies.

## Resource profile
Container memory ceilings:
- MySQL: 1200 MB
- Redis: 256 MB
- API: 700 MB
- Web: 700 MB

These are container limits, not a guarantee that the Docker Desktop VM stays below 3 GB.
Windows and Docker Desktop/WSL2 require additional memory.

## Security
- `.env` is ignored by Git.
- `.env.example` contains placeholders only.
- Change every placeholder secret before use.
- Do not expose MySQL or Redis to untrusted networks.
- This development stack is not production hardened.
- Do not use real patient-identifiable data.
