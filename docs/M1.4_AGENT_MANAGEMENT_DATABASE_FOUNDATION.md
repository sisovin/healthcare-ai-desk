# M1.4 — Agent Management Database Foundation

## Objective
Create a secure database foundation for Agent Management that is fully aligned with the M1.3 organization security model.

## Delivered schema

### 1) `agent_profiles`
Organization-scoped agent registry:
- Agent identity: `id`, `name`, `slug`
- Agent behavior/config: `role`, `description`, `system_prompt`
- Model configuration: `model_provider`, `model_name`
- Lifecycle: `status` (`draft`, `active`, `disabled`, `archived`)
- Traceability: `created_by_user_id`, timestamps

Security constraints:
- `organization_id` required and FK to `organizations`
- Unique slug per organization (`uq_agent_profiles_org_slug`)
- Status check constraint (`ck_agent_profiles_status`)

### 2) `agent_project_assignments`
Organization-scoped assignment table:
- Links an agent profile to a project in the same organization
- Tracks `assigned_by_user_id` and assignment timestamp

Security constraints:
- Composite FK `(organization_id, agent_profile_id)` -> `agent_profiles`
- Composite FK `(organization_id, project_id)` -> `projects`
- Uniqueness per org-agent-project triplet

This prevents cross-organization assignment leakage at DB level.
